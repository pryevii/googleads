# 10.2 Ad Optimization

*Converted from `PPC Co Pilot/Ecom Accelerator/10. Search Optimization/10.2 Ad Optimization.rtf`*

**When it comes to ads just remember:**

- Test impactful/meaningful tests
- Run ad tests in controlled experiments
- Utilize all ad assets that make sense
- Review for ad and ad asset disapprovals often

1. Cleaning Existing Ads:

- Review asset details and performance labels
- Remove low-performing headlines and descriptions
- Replace with new, unique content

2. Adding New RSAs:

- Create a new RSA in the same ad group
- Test different themes (e.g., price, features, comparisons)
- Ensure uniqueness in headlines and descriptions

3. Campaign Experiments:

- Create a custom experiment at the campaign level
- Set up a control (original) and test (new ad) group
- Choose traffic split (e.g., 50/50) and duration
- Enable sync to maintain consistency in other settings

4. Ad Variations:

- Use rules to test specific elements across multiple ads
- Options include find and replace, URL updates, and text updates
- Test headline changes, call-to-actions, or landing pages
- Set experiment split and duration

5. Best Practices:

- Keep track of tested ad copy and performance
- Focus on meaningful differences between ads
- Consider pinned vs. unpinned headline tests
- Monitor performance metrics (CTR, conversion rate, etc.)

6. Reporting and Analysis:

- Use built-in experiment reporting tools
- Compare performance between original and test versions
- Make data-driven decisions on which variations to keep

7. Continuous Optimization:

- Regularly review and update ad copy based on test results
- Apply learnings to future ad creation and testing

Remember, the goal of testing is to improve ad performance continuously. Use these methods to systematically test different elements of your RSAs and apply the insights gained to optimize your campaigns.
