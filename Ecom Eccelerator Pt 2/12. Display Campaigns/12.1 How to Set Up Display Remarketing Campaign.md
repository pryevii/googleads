# 12.1 How to Set Up Display Remarketing Campaign

*Converted from `PPC Co Pilot/Ecom Accelerator/12. Display Campaigns/12.1 How to Set Up Display Remarketing Campaign.rtf`*

**Prerequisites: Audience Setup**

**Data Sources Setup**

1. Configure data sources in Audience Manager:

- Google Ads tag (recommended)
- GA4 connection
- YouTube channel (optional)
- Customer lists (optional)

**Creating Remarketing Audiences**

1. Navigate to Data Segments
2. Create website visitor audiences:

- 7-day audience
- 30-day audience
- 60-90 day audience
- 540-day audience (maximum, useful for holidays)

**Campaign Setup Process**

**Initial Configuration**

1. Create new campaign without goals guidance
2. Select Display as campaign type
3. Choose appropriate conversion goals
4. Use clear naming convention (e.g., "D\_REM\_ConvertersExcluded")

**Basic Settings**

1. Location targeting:

- Select target locations
- Use "Presence" targeting (not "Presence or interest")

2. Language settings
3. Device settings:

- Consider excluding tablets initially
- Focus on desktop and mobile first

**Dynamic Ads Setup (E-commerce Only)**

1. Connect Merchant Center feed
2. Enable dynamic product ads
3. Configure product feed settings

**Bidding and Budget Strategy**

**Budget Setting**

- Set daily budget ≥ average CPA
- Example: If average CPA is $200, set minimum $200/day budget
- Allows room for optimization

**Bidding Strategy Options**

1. New Campaigns:

- Start with Maximize Conversions
- Or Maximize Conversion Value

2. Established Accounts:

- Consider Target CPA
- Or Target ROAS if e-commerce
- Base targets on historical data

**Audience Targeting Configuration**

**Critical Settings**

1. Add remarketing audience
2. IMPORTANT: Disable "Optimize targeting"

- Prevents showing ads to non-remarketing audiences
- Common error that wastes budget

**Exclusions**

1. Set up converter exclusions
2. Exclude mobile apps:

- Use Google Ads Editor for bulk exclusion
- Select "All apps" at campaign level

**Ad Creation**

**Asset Requirements**

1. Images (up to 15)
2. Logos (required)
3. Headlines (up to 5)
4. Long headline
5. Descriptions (up to 5)
6. Final URL

**Format Settings**

1. Enable asset enhancements
2. Disable auto-generated video
3. Consider native formats
4. Optional:

- Custom colors
- Custom call-to-action text

**Performance Considerations**

**Performance Max Integration**

- Expect lower volume with Performance Max running
- Performance Max typically takes priority for remarketing
- Still viable but may need adjusted expectations

**Optimization Tips**

1. Regular placement review
2. Monitor audience performance
3. Test different ad formats
4. Adjust bidding based on performance
5. Review exclusions regularly

**Best Practices**

**Campaign Management**

1. Use clear naming conventions
2. Monitor placement reports
3. Regular budget reviews
4. Test various ad formats
5. Keep audience lists updated

**Common Pitfalls to Avoid**

1. Leaving optimize targeting enabled
2. Not excluding converters
3. Including mobile apps
4. Setting budget too low
5. Missing audience setup
6. Poor ad asset quality

**Monitoring and Maintenance**

1. Regular review of placement reports
2. Monitor audience size and refresh rates
3. Check exclusion effectiveness
4. Update ad assets periodically
5. Review bidding strategy performance
6. Monitor conversion tracking

**Additional Considerations**

- Regular audience list updates
- Seasonal strategy adjustments
- Creative refresh schedule
- Placement monitoring
- Performance comparison with other campaigns
- Regular bid strategy review
