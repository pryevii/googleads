# 8.1 How to Set Up Dynamic Search Ads (DSA)

*Converted from `PPC Co Pilot/Ecom Accelerator/8. Dynamic Search Ads/8.1 How to Set Up Dynamic Search Ads (DSA).rtf`*

1. Introduction to DSA:

- Automatically generated ads based on website content
- Useful for keyword harvesting and filling gaps in keyword coverage

2. Benefits of DSA:

- Saves time on keyword research and ad creation
- Captures long-tail keywords
- Complements standard search campaigns

3. Setting Up DSA:

- Can be set up as a separate campaign or ad group within a standard search campaign
- Targeting options: categories, specific web pages, URL rules, or all web pages
- Recommended: Use URL-based targeting for better control

4. Ad Creation:

- Headlines and URLs are dynamically generated
- Advertisers can create descriptions

5. Monitoring Performance:

- Review search terms report to see what queries triggered ads
- Analyze dynamically generated headlines

6. Negative Keywords and Targeting:

- Use negative keywords to prevent unwanted traffic (e.g., brand terms, competitor names)
- Set up negative dynamic ad targets to exclude specific pages or content

7. Best Practices:

- Combine DSA with standard search campaigns
- Regularly review search terms and landing pages
- Use URL rules to target specific product categories or brands

8. Advanced Strategy:

- Create a DSA campaign targeting all web pages, but limit to a remarketing audience
- This approach combines broad targeting with a warm audience

9. Potential Issues:

- May show ads for irrelevant content (e.g., blog posts)
- Could accidentally include competitor names in headlines

10. Optimization:

- Continuously refine negative keywords and negative dynamic ad targets
- Use insights from DSA to inform keyword strategies for standard campaigns
