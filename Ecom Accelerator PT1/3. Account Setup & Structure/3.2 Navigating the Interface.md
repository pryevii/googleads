**WHERE TO FIND IMPORTANT SETTINGS**

Once you understand the hierarchy, the next thing to learn is where the settings outside the hierarchy live. Everything in Google Ads is in one of four places: Goals, Audiences, Tools, or Admin. Once you know which, you can find anything in 3 clicks.

**🎯 GOALS (left sidebar)**

This is where you define what counts as a win.

What lives here:

Conversions — every action you're tracking (purchase, lead, signup)

Conversion Summary — performance of each conversion action

Attribution — which models you use (last-click vs data-driven)

When to come here:

Setting up a new conversion

Checking if a conversion is firing correctly

Changing what counts as the optimization target

**👥 AUDIENCES (left sidebar)**

This is where you build and manage who you target or observe.

What lives here:

Audience Manager — your remarketing lists, customer match lists, custom segments

Audience Insights — who's actually converting (demographics, interests)

Custom Segments — keyword and URL based audiences for Display / PMax

When to come here:

Uploading a customer list

Building a remarketing audience

Reviewing who Google says is converting on your account

**🛠️ TOOLS (left sidebar or top menu)**

Your utility belt — anything that operates across multiple campaigns lives here.

What lives here:

Scripts — automation code that runs on a schedule (Tools → Bulk Actions → Scripts)

Bid Strategies — portfolio bid strategies shared across campaigns

Shared Library — negative keyword lists, placement exclusion lists

Business Data — feeds (sitelinks, prices, callouts, dynamic ad targets)

Asset Library — images, videos, logos used in PMax / Demand Gen

Bulk Actions — upload changes via spreadsheet

When to come here:

Adding a script

Building a negative keyword list to apply to multiple campaigns

Bulk-uploading changes via CSV

**⚙️ ADMIN (left sidebar, gear icon)**

Account-level configuration — anything that affects the whole account, not individual campaigns.

What lives here:

Account Access (User Access) — who can log in and what permissions they have

Billing — payment method, invoices, promo credits

Account Preferences — time zone, currency, auto-tagging, notifications

Account Settings — account name, business info, communication preferences

Linked Accounts — Google Analytics, Merchant Center, YouTube, Search Console

Sub-Account Settings — manage child accounts (MCC only)

When to come here:

Granting a new user access

Updating credit card or billing info

Linking GA4 or Merchant Center

Changing time zone or currency (warning: time zone is permanent)

**QUICK NAVIGATION CHEAT SHEET**

Set up a conversion → Goals → Conversions → Summary

Upload a customer list → Audiences → Your data segments

Add a Google Ads script → Tools → Bulk Actions → Scripts

Add a negative keyword list → Tools → Shared Library → Negative Keyword Lists

Grant team member access → Admin → Account Access

Update billing info → Admin → Billing → Settings

Link Google Analytics → Admin → Linked Accounts

Run a bulk upload → Tools → Bulk Actions → Uploads

**💡 ONE SHORTCUT TO RULE THEM ALL**

The search bar at the top of Google Ads (or hit / on your keyboard) finds anything. Type "negative" — it surfaces negative keyword lists. Type "billing" — it jumps you to billing settings.

When in doubt, search.
