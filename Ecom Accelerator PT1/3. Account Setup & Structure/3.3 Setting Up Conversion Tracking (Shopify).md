# 3.3 Setting Up Conversion Tracking (Shopify)

*Converted from `PPC Co Pilot/Ecom Accelerator/3. Account Setup & Structure/3.3 Setting Up Conversion Tracking (Shopify).rtf`*

**Two recommended methods:**

1. Simple Method (Using App):

- Install "Google and YouTube" app in Shopify
- Connect Google account and Merchant Center
- Enable conversion tracking in app settings
- Link Shopify in Google Ads data manager

1. Advanced Method (Manual Setup):

- Create conversion action in Google Ads
- Add custom pixel in Shopify settings
- Implement conversion tracking code with proper IDs
- Test conversion tracking on checkout

**Best Practices:**

- Implement both methods as backup
- Set only one tracking method as "primary" to avoid double-counting
