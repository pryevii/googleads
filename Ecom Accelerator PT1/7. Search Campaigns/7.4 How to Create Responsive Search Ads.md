# 7.4 How to Create Responsive Search Ads

*Converted from `PPC Co Pilot/Ecom Accelerator/7. Search Campaigns/7.4 How to Create Responsive Search Ads.rtf`*

1. Introduction to RSAs:

- Allows up to 15 headlines and 4 descriptions
- Google automatically combines these to create different ad variations

2. Ad Creation Process:

- Start with a clear URL and display path
- Create unique, relevant headlines and descriptions
- Utilize ad assets (images, sitelinks, etc.)

3. Ad Copy Template:

- Message to intent (include relevant keywords)
- Features and benefits
- Price, promotions, guarantees
- Social proof (reviews, awards)
- Call-to-action

4. Best Practices:

- Avoid repeating the same information in different ways
- Use all available headline and description slots if possible, but prioritize uniqueness
- Incorporate keywords naturally into ad copy
- Use specific numbers and details when possible

5. Ad Strength:

- Don't overly focus on Google's ad strength metric
- Ad strength doesn't directly affect ad serving or performance
- Focus on writing impactful, relevant ad copy instead

6. Performance Considerations:

- Large number of possible combinations with 15 headlines and 4 descriptions
- Smaller accounts may benefit from fewer headlines to allow for more thorough testing
- Ads typically need around 2,000 impressions in top positions over 30 days for performance ratings

7. Key Focus Areas:

- Write ad copy that resonates with searchers
- Monitor click-through rate and conversion rate
- Focus on meeting campaign goals (CPA, ROAS) rather than ad strength metrics

8. Additional Resources:

- Utilize chat GPT for ad creation ideas
- Refer to website content and customer reviews for inspiration
