# 7.6 Setting Budgets and Bid Strategies

*Converted from `PPC Co Pilot/Ecom Accelerator/7. Search Campaigns/7.6 Setting Budgets and Bid Strategies.rtf`*

**✅ Campaign Budget Requirements**

**Minimum Daily Budget Guidelines**:

- **Starting Point**: Budget for at least 10 clicks per day

- Calculate by multiplying expected CPC by 10 (e.g., if average CPC is $2, budget at least $20/day)
- Allows Google's algorithm enough data points to learn efficiently
- Prevents campaigns from being throttled throughout the day

**Budget for Smart Bidding Transitions**:

- **Goal**: Generate 30+ conversions per month for effective smart bidding
- **Budget Formula**: (Target monthly conversions × Expected cost per conversion) ÷ 30 days

- Example: For 30 conversions at $50 each = $1,500/month or $50/day

- **Scaling Consideration**: If target CPA is high, ensure budget allows for consistent daily spend

**Budget Adjustments Based on Performance**:

- Increase budget when campaigns consistently hit daily budget limits but maintain target metrics
- Rebalance budget across campaigns based on conversion performance
- For new campaigns, allow 2-4 weeks at consistent budget before making major changes

**Common Budget Pitfalls**:

- Insufficient budget causing data collection to take too long (extends learning phase)
- Frequent budget changes disrupting algorithm learning

Uneven daily spend preventing consistent data patterns

**✅ Brand New Accounts**

**Initial Strategy**:

- **Manual CPC**: Conservative approach, best for small budgets
- **Maximize Clicks**: Aggressive approach, best for larger budgets

**Data Collection (2-4 weeks)**:

1. Set competitive bids
2. Monitor performance signals
3. Gather click and impression data
4. Identify emerging conversion patterns

**Transition to Smart Bidding**:

- **With 30+ conversions in 30 days**:

- Use Maximize Conversions or Target CPA

- **With 15-29 conversions in 30 days**:

- Use Maximize Conversions
- Avoid Target CPA/ROAS until more data is available

- **When setting Target CPA or ROAS goals**:

- Start with the average of last 30 days (e.g., if currently at $75 CPA, set target at $75)
- Gradually optimize toward desired targets

**✅ New Campaigns with New Keywords**

**Approach**:

- Treat as a brand new account even if your account
- Begin with Manual CPC or Maximize Clicks
- For established accounts with consistent conversion tracking:

- Can test Maximize Conversions as starting point
- If volume doesn't materialize within a week, revert to Manual CPC/Max Clicks

**Goal**:

- Work toward 30+ conversions in 30 days to enable smart bidding
- Follow same data collection and transition approach as brand new accounts

**✅ New Campaigns with Existing Keywords**

**Approach (with significant historical data)**:

- Start with Maximize Conversions for quick ramp-up
- With 30+ conversions in past 30 days for these specific keywords:

- Can immediately use Target CPA
- Set targets based on the specific keyword set's historical performance
- Example: If Plumbing keywords averaged $100 CPA with 50 conversions in 30 days, set new campaign to $100

**Advantage**:

- Google already understands conversion patterns for these keywords
- Historical performance data guides smart bidding decisions

**✅ Brand Campaigns**

**Primary Focus**: Impression share, not conversion metrics

**Recommended Strategies**:

- **Manual CPC**: Most control over costs
- **Target Impression Share**: Set for absolute top position (position #1)

**Testing Smart Bidding**:

1. Document metrics before switching
2. Test Target CPA or Target ROAS if desired
3. After 2-4 weeks, compare:

- Impression share
- CPC
- Conversions

4. If smart bidding increases CPCs without additional gains, revert to manual

**Key Consideration**:

- Often smart bidding increases CPCs for brand terms with no additional benefit
- Prioritize controlling costs while maintaining high impression share

**🔑 Keys to Success (All Scenarios)**

- Regular monitoring of KPIs
- Proper conversion tracking setup
- Appropriate budget allocation
- Patience through learning phases
- Ongoing search term report analysis
- Scientific approach to testing changes
