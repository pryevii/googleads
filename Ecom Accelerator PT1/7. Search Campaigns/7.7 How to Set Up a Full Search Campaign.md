# 7.7 How to Set Up a Full Search Campaign

*Converted from `PPC Co Pilot/Ecom Accelerator/7. Search Campaigns/7.7 How to Set Up a Full Search Campaign.rtf`*

**Initial Campaign Creation**

1. Click the blue plus button to create a new campaign
2. Select "Create a campaign without goals guidance" (campaign objectives don't affect performance, they only filter available settings)
3. Choose "Search" as the campaign type

**Campaign Settings**

**Basic Setup**

- Use clear naming conventions for campaigns (e.g., "S\_CarpetCleaning\_FortWayne" where S = Search)
- For new campaigns, start with Max Clicks or Manual CPC bidding strategy
- Set a maximum CPC bid limit based on keyword research
- Only switch to conversion-based bidding after achieving around 30 conversions per month

**Network Settings**

- Turn off Display Network (never mix with search campaigns)
- Initially disable Search Partners Network (can enable later once campaign is performing well)

**Location Settings**

- Set specific geographic targeting (city, radius, or zip codes)
- Important: Under location options, select "Presence: people in or regularly in your targeted locations" (not "Presence or interest")
- Choose appropriate language settings

**Schedule and Timing**

- Set campaign schedule if needed (e.g., business hours only)
- Verify correct time zone
- Don't set an end date unless running a specific promotion

**Keywords and Match Types**

**Keyword Strategy**

- Start with exact match and phrase match keywords (not broad match)
- Only use broad match later when:

- Campaign is well-optimized
- Using conversion-based smart bidding
- Meeting performance goals

**Ad Group Structure**

- Group similar intent keywords together
- Different intents (e.g., commercial vs. residential) should be in separate ad groups
- No need for single-keyword ad groups (SKAGs) anymore

**Ad Creation**

- Create multiple headlines (up to 15 allowed)
- Write multiple descriptions (up to 4 allowed)
- Include relevant display paths
- Add appropriate assets (images, sitelinks, callouts, etc.)

**Post-Setup Optimization**

**Device Adjustments**

- Consider starting without tablet traffic (-100% bid adjustment)
- Focus on desktop and mobile first
- Add tablets back once campaign is performing well

**Negative Keywords**

- Add negative keywords before launch:

- Competitor brand names
- Irrelevant product terms
- Out-of-area locations
- Irrelevant purchase intents

**Budget Setting**

- Set daily budget to allow for at least 10 clicks per day
- This ensures enough data for optimization

**Performance Monitoring**

- Monitor search terms report regularly
- Adjust bid strategies based on performance
- Consider enabling search partners once campaign is stable
- Track conversion data to determine when to switch to smart bidding

**Best Practices**

- Start with tighter targeting and expand gradually
- Focus on quality over quantity in the beginning
- Use clear naming conventions throughout
- Document all major changes and optimizations
- Regular review of search terms and performance metrics
