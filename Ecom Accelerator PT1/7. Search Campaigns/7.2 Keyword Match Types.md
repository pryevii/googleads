# 7.2 Keyword Match Types

*Converted from `PPC Co Pilot/Ecom Accelerator/7. Search Campaigns/7.2 Keyword Match Types.rtfd`*

1. Types of Keyword Match Types:

- Exact Match: [keyword]
- Phrase Match: "keyword"
- Broad Match: keyword

2. Exact Match:

- Ads may show for searches with the same meaning as the keyword
- Provides tightest control but may limit volume
- Often has highest conversion rates but can be most expensive

3. Phrase Match:

- Ads may show for searches that include the meaning of the keyword
- Moderate matching, more flexible than exact but more controlled than broad
- Good balance between control and reach

4. Broad Match:

- Ads may show for searches related to the keyword
- Provides the most reach but least control
- Can show for unrelated searches, requiring diligent negative keyword management

7. Performance Characteristics:

- Exact match often has highest conversion rates and CTR
- Phrase match typically performs between exact and broad
- Broad match usually provides highest volume but lowest conversion rates

8. Best Practices:

- Start new campaigns with exact and phrase match
- Add broad match only after campaign is optimized and using smart bidding
- Use broad match with caution and monitor search terms closely
- Regularly review search terms report for all match types

9. Considerations:

- Exact match is no longer truly "exact" and can show for close variants
- Phrase match behaves more loosely than in the past
- Broad match works best with smart bidding strategies

10. Negative Keywords:

- Essential for all match types, but especially for broad match
- Regularly review and update based on search term performance
